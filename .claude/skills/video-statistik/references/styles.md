# 25 gaya video — mana yang sesuai untuk statistik rasmi

Prinsip: produk data rasmi perlu nampak **boleh dipercayai dahulu, menarik kemudian**. Gaya yang
"main-main" atau mengelirukan mengurangkan kredibiliti angka.

| Gaya | Guna? | Di mana / sebab |
|---|---|---|
| Cinematic / Film Look | Ya | Pembukaan angkasa: jalur 2.39:1, bijian halus, cahaya lembut |
| Drone / Aerial Establishing | Ya | Penerbangan Bumi → kampung (MapLibre + Esri) — tulang belakang cerita "dari dunia ke kampung" |
| Kinetic Typography | Ya | Tajuk perkataan demi perkataan (`K/kDraw`); satu idea per baris |
| Infographic Animation | Ya | Kiraan 258 / 222 / 21,566; nombor mesti betul dan bersumber |
| Lottie / UI Motion | Ya | Kursor, ketikan, ripple, callout pada skrin aplikasi **sebenar** |
| 2.5D Parallax | Ya | Bingkai pelayar/telefon condong, dinding bendera |
| Split-Screen / Multi-Panel | Ya | Parlimen vs kampung (16:9 kiri-kanan, 9:16 atas-bawah) |
| Lower Third & Title Card | Ya | Label ciri; kicker emas + tajuk |
| Ken Burns | Ya | Zum perlahan dalam tangkapan skrin dan imej udara |
| Motion Collage / Montage | Ya | Karusel ciri, montaj "sumber · kualiti · muat turun" |
| Minimalist Clean | Ya | Kad penutup: logo, URL, penafian, kredit |
| Isometric / Explainer | Sebahagian | Susunan peranti 2.5D; isometrik penuh menyukarkan bacaan skrin |
| Mix-Media | Sebahagian | Gabungan 3D + tangkapan skrin + grafik sudah cukup |
| Time-Lapse / Hyperlapse | Sebahagian | Peralihan siang/malam pada Bumi 3D sahaja; tiada rakaman sebenar |
| Slow Motion / Speed Ramp | Sebahagian | Lengkung zum penerbangan (laju di tengah, perlahan di hujung) |
| VOX Style | Jarang | Boleh untuk kisah analisis bertulis; bukan untuk promo sistem |
| B-roll Text | Jarang | Perlu rakaman B-roll sebenar (tiada dalam sesi) |
| Documentary / Talking Head | Tidak | Perlu penyampai sebenar; jangan jana wajah palsu |
| Cinemagraph | Tidak | Perlu rakaman video asal |
| Whiteboard / Doodle / Sketch | Tidak | Nada kanak-kanak; kurang sesuai untuk angka rasmi |
| Stop-Motion | Tidak | Perlu objek fizikal; nampak amatur jika dipalsukan |
| Glitch / Digital Distortion | Tidak | Memberi kesan "data rosak" — bertentangan dengan mesej kualiti |
| Retro / Vintage Film Grain | Tidak | Bijian ringan sahaja; gaya retro mengaburkan angka |

Muzik: asli (sintesis) supaya bebas hak cipta; tawarkan suara latar hanya jika pengguna mahu.
